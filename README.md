
# CrowdForage – Decentralized Crowdfunding Platform

![CrowdForage](https://github.com/user-attachments/assets/aa416775-68eb-4b61-a4f4-9fc0dbf35acf)

CrowdForage is a decentralized crowdfunding platform that enables users to create fundraising campaigns and contribute funds using the Ethereum blockchain. By integrating MetaMask, the application allows users to connect their wallets, authorize transactions, and participate in transparent, blockchain-based fundraising.

---

## 🚀 Features

- **Campaign Creation:** Create fundraising campaigns by providing a title, description, and target amount.
- **MetaMask Wallet Integration:** Connect a MetaMask wallet to interact with the application and authorize Ethereum transactions.
- **Blockchain Transactions:** Record campaign creation and donations through blockchain transactions.
- **Transparency:** Allow users to verify transactions and fundraising activity on the blockchain.
- **Decentralized Architecture:** Use smart contracts and a local blockchain network to manage campaign-related operations during development.

---

## 🛠️ Technology Stack

- **Frontend:** React.js – for building an interactive user interface.
- **Smart Contracts:** Solidity – for implementing crowdfunding logic on the blockchain.
- **Development Environment:** Hardhat – for developing, testing, and deploying smart contracts.
- **Wallet Integration:** MetaMask – for wallet connectivity and transaction authorization.
- **Blockchain:** Ethereum – for executing smart contracts and recording transactions.
